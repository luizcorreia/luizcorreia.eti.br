# Luiz Correia - Blog

[**https://luizcorreia.eti.br**](luizcorreia.eti.br).

Esse é o meu blog pessoal, gerado estaticamente com
[Astro](https://astro.build/). Os posts continuam em `posts/*.md`, com os slugs
derivados dos nomes dos arquivos.

## Desenvolvimento

```bash
npm start
npm test
npm run build
```

## Nota

Ele foi baseado no do blog do [Willian Justen](https://github.com/willianjusten/willianjusten.com.br)
